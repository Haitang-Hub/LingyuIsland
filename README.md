# 灵屿岛

桌面文件隐私遮盖与还原工具。把文件拖到屏幕顶部的「灵动岛」上，自动识别敏感信息并生成结果副本；文本、Office 文件的遮盖可无损还原，PDF 与图片为不可逆遮盖。

当前版本：**v1.14.3**。文档中的姓名、号码、地址与机构均为虚构示例。

- 安装包（国内，推荐）：[CNB Releases](https://cnb.cool/haitang.hub/LingyuIsland/-/releases)
- 安装包（备用）：[GitHub Releases](https://github.com/Haitang-Hub/LingyuIsland/releases/latest)
- 源码更新通道：[npm 包](https://www.npmjs.com/package/@haitang-hub/lingyu-island)（优先走国内镜像 `registry.npmmirror.com`）

## 40 秒上手

```bash
# 源码运行
npm install
npm start
```

Windows 也可双击 `启动灵屿岛.bat`；macOS 首次执行 `chmod +x 启动灵屿岛.command` 后双击即可。

首次使用：

1. 点击胶囊展开面板 → **设置** → 选择**文件根目录**。未设置根目录时拖入文件不会处理。
2. 把文件或文件夹拖到屏幕顶部胶囊。明文生成 `文件名_屏蔽.ext`；带有效还原编码的文件生成 `文件名_还原.ext`。
3. 结果只写入根目录，**不会复制原文件进去**，也不会改动原位置的文件。需要时可设置「处理后移入回收站」。

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 拖入即处理 | 拖入文件/文件夹后自动判断是明文还是已遮盖文件，批量生成结果；胶囊轮播显示「已完成 / 产物 / 未完成原因」，红色项必带说明。 |
| 可逆遮盖 | 文本与 Office 文件在敏感值位置写入 `类型标签 + 还原编码`，例如 `138****5678〔手机号·a3f2b1〕`。保留首尾特征，便于判断内容类型。 |
| 随时还原 | 把已遮盖文件再次拖入即可还原；也可在「文本恢复」页粘贴含编码的文本。映射库丢失时只能识别编码外观，无法还原真实值。 |
| 剪贴板恢复 | 复制了含编码的内容时，胶囊提示「识别到含屏蔽信息」；点右侧「还原文本」按钮才写回剪贴板，只作用于当前那段文本。 |
| 不可逆遮盖 | PDF 与图片用黑框覆盖敏感区域，输出 `文件名_屏蔽.ext`。不写映射库、不支持还原，也不复制原文件到根目录。 |
| 快速查找 | 配置文件根目录后自动建索引并监听变更；按「全部 / 文档 / 表格 / 图片 / 文本 / 其他」筛选，按钮数字为命中数。回车打开，Shift+回车定位。 |
| 多分辨率适配 | 按显示器工作区与系统缩放自动调整胶囊和面板；面板宽高独立，可切换「细长 / 标准 / 宽扁」，始终完整落在屏幕内。 |
| 外观定制 | 8 套主题、9 种强调色、透明度 / 圆角 / 字号 / 毛玻璃 / 面板尺寸 / 动效开关，支持自定义图片或视频背景。 |
| 本地更新 | 设置中检查更新；源码直跑优先从国内 npm 镜像获取，安装版从 CNB Releases（国内通道）获取，均保留官方源兜底。下载与安装需手动确认。 |

## 文件处理方式

| 类型 | 支持格式 | 处理方式 | 可否还原 |
| --- | --- | --- | --- |
| 文本 | txt / md / csv / json / 代码等，UTF-8 / GBK 自动识别 | 段落级检测后写入带标签的还原编码 | ✅ |
| Office | docx / xlsx / pptx | 解包 OOXML，按段落拼接文本节点后统一检测，再把编辑映射写回原节点 | ✅ |
| 老式 Word | doc / dot（OLE2 二进制） | 本地转换为临时 docx 后走同一管道，结果以 `.docx` 落地；转换器优先级为 LibreOffice → Word COM | ✅ |
| PDF | pdf | 文本层定位，或内置 OCR 识别扫描页；仅栅格化命中页并画黑框，输出纯图像 PDF | ❌ |
| 图片 | jpg / jpeg / png / webp / bmp / gif / tif | 内置 OCR 识别文字，画黑框后重新编码，原 EXIF / 元数据丢失 | ❌ |

- 单文件上限 **20 MB**。无敏感信息时提示 `no-pii`，不产出文件。
- PDF / 图片每次拖入都会重新处理，不会因文件名带 `_屏蔽` 而跳过。
- PDF 默认渲染精度 200 DPI；高级用户可在用户数据目录的 `settings.json` 中用 `pdfRedact.dpi`（96–400）和 `pdfRedact.ocrEngineDir`（外部 OCR 引擎目录）覆盖默认值。
- 扫描件 PDF 无文本层且 OCR 引擎不可用时返回 `pdf-no-text`，不会静默输出未遮盖文件。

## 敏感信息识别

### 默认开启

| 类别 | 说明 |
| --- | --- |
| 手机号、固定电话 / 传真 | 手机号含校验边界；固定电话含 400 号码 |
| 身份证号、护照号 | 身份证按 18 位结构校验；虚构测试号也可覆盖 |
| 银行卡号 | BIN 规则 + Luhn 校验 |
| 电子邮箱 | 常规邮箱格式 |
| 中文姓名 | 语境驱动，详见下文规则说明 |
| 家庭住址 / 位置信息 | 行政区划链 + 道路 / 小区 / 门牌等落点要素 |
| 机构名称 | 公司、事务所、学校、医院、公共机构等 |
| 车牌号、案号、执业证号 | 结构化编号 |
| 统一社会信用代码 | GB 32100 校验位验算 |

### 默认关闭（设置中按需开启）

- 微信 / QQ 号：关键词引导，聊天记录场景建议开启。
- 港澳台证件：回乡证、台胞证。

### 设计上不屏蔽

性别、年龄、出生日期、民族等依法用于判断的信息不屏蔽；纯行政区划叙述（无具体落点）不屏蔽；机构名与地址不会被误切成姓名片段。

### 识别规则要点

- **姓名**：不依赖姓氏表或姓名白名单。通过角色 / 头衔 / 字段 / 性别结构 / 强敏感信息邻近 / 被动与所有格结构锚定；冒号后是完整话语时按话语处理。确认后按哈希在同一批文件中传播。
- **机构**：从后缀向左回溯字号，仅在名称含行政区划层级或可识别省市信息时屏蔽；统一为 `某X……后缀`，不保留字号首字。
- **地址**：按身份证地址格式解析省→市→县/区→镇/乡/街道→村/社区链，并要求道路、小区、门牌、楼栋等落点要素；统一为 `某X……尾字` 形态。
- **案号**：统一为「头部 + `……` + 号」；头部按相邻机构、省市简称或年份括号分别处理。
- **跨节点**：Word 常把一个词拆进多个 `<w:t>`。同一段落内的文本节点会先拼接再检测，然后把编辑映射写回各节点，run / 标签结构不变。
- **两遍扫描**：批量导入时先预扫全部文件收集实体，再逐文件检测，使同批文件中只出现一次的真实姓名也能被覆盖。

## 结果文件与还原

- 文件一律写为 `原文件名_屏蔽.ext` 或 `原文件名_还原.ext`；还原产物再次遮盖时回到原名，不产生 `A_还原_屏蔽.docx` 这样的叠名。
- 同名策略：默认「保留两份」，自动加 `_02`、`_03` 序号；「覆盖同名」启用时有二次确认。
- 只有编码外观但映射库里查不到的文件按明文处理；这类文本可在「文本恢复」页粘贴后尝试手动还原。
- 映射库丢失或编码被改动时会明确提示无法还原，不会输出错误内容。

## 使用流程

1. 拖入文件 → 自动判断意图 → 明文生成 `_屏蔽`，含有效编码生成 `_还原`。
2. 复制了被遮盖内容 → 胶囊提示 → 点「还原文本」，或在「文本恢复」页粘贴。
3. 展开面板 → 「快速查找」→ 输入文件名 → 类别筛选 → 回车打开 / Shift+回车定位。
4. 设置中可以调整检测项、剪贴板识别、自动收起（5–3600 秒，可关闭）、开机自启、导入与同名策略、外观、清空记录。
5. 右键胶囊可隐藏灵动岛；悬停屏幕顶部细线或点击托盘图标可唤回。托盘还提供显示 / 隐藏、开机自启与退出。

## 隐私与安全

- 文件处理、检测、OCR 均在**本机**完成；文件内容与映射库不会上传。
- 仅「检查更新 / 下载更新」会访问国内 npm 镜像 / npm 官方源或 CNB Releases；GitHub 仅作备用下载地址。
- 映射库存于 Electron 用户数据目录（Windows 通常在 `%APPDATA%/<应用名>`），优先用系统安全存储加密；不可用时退化为明文文件，并在「设置 → 数据」显示状态。
- 清空记录不会删除已生成的文件或映射库。请勿删除映射库，否则已遮盖内容无法还原。
- 姓名跨文件传播缓存只保存哈希，不保存明文。

## v1.14.x 性能与稳定性

- OCR 引擎有界复用：小图复用避免冷启动；大图或累计多次后回收重启，防止长任务逐渐变慢。
- PDF / 图片遮盖转移到独立工作进程池，渲染、合成与编码不再冻结主界面。
- 数字版 PDF 只读文本层检测，**仅栅格化命中页**；无命中直接跳过。10 页 1 命中的实测耗时从约 6.4 秒降至约 0.5 秒。
- 旧 OCR 子进程退出 / 错误事件不再误伤新请求。
- 灵动岛悬停看门狗按状态自适应轮询（收起 60ms / 展开 200ms / 不可见 1Hz），并修复 Windows 偶发丢失置顶的问题。
- 更新下载优先走国内通道：安装版从 CNB Releases 获取，源码直跑优先国内 npm 镜像；不再依赖 GitHub 的海外下载速度。
- 批量处理复用姓名缓存、映射新增才落盘、剪贴板关闭时不读系统剪贴板，减少重复 IO 与轮询开销。

## 打包与发布

```bash
npm run dist            # 打包到 release/v<version>/
npm run clean:release   # 只清理历史产物，保留当前版本目录
```

- `scripts/dist.js` 复用本地 Electron 并配置国内镜像，产物包括安装包、blockmap、`latest.yml` 与 `win-unpacked`；不再生成 zip。
- 每次打包前清理历史产物；被占用而删不掉的文件会打印路径，重启后再清理。
- 不要直接运行 `npx electron-builder --win`，否则产物会散落到 `release` 根目录。
- 安装版更新源写进 `app-update.yml`（`provider: generic` → CNB）。发版时除 GitHub Release 外，**必须**把安装包、blockmap、`latest.yml` 同步到 [CNB Releases](https://cnb.cool/haitang.hub/LingyuIsland/-/releases)，否则更新检查会拿到旧版本。`npm run dist` 会校验更新源未被改回 GitHub。

## 已知限制

- PDF / 图片遮盖不可逆；图片重编码后 EXIF / 元数据丢失，重要文件请自行留存原件。
- OCR 对手写体、艺术字、低对比度图片的识别率有限；扫描件 OCR 速度受页数与清晰度影响。
- 关键词与数值被拆到不同段落时可能漏检；段落内部跨 run 的敏感值已支持。
- 无任何语境锚点的孤立姓名仍可能漏检；紧邻角色标签但其实是普通词的情况已做边界过滤。
- 还原依赖映射库与未被改动的编码；编码被修改或映射库删除后无法恢复。
- 单文件超过 20 MB 会跳过；加密或密码保护的 Office 文件需先在原应用中解除保护。
- 更新检查需要网络；完全离线环境下可忽略更新提示，文件处理本身不依赖网络。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面框架 | Electron 33：主进程、渲染进程、utilityProcess 任务池 |
| UI | 原生 HTML / CSS / JS，屏幕胶囊 + 主面板双窗口，无前端框架 |
| 核心引擎 | 纯 Node.js 检测器 / 遮盖恢复引擎 / 文件管道，可脱离 Electron 测试 |
| 文本与 Office | iconv-lite 编码识别；adm-zip 解包 OOXML 后按段落拼接文本节点 |
| PDF | pdfjs-dist 提取文本层坐标；pdf-lib + fontkit 画黑框并生成纯图像 PDF |
| 图片 | @napi-rs/canvas 合成、栅格化与重编码 |
| OCR | 内置 RapidOCR-json，多语言模型随包分发，有界复用 |
| 老式 .doc | LibreOffice → Windows Word COM 本地转换 |
| 安全存储 | Electron safeStorage：Windows DPAPI / macOS Keychain |
| 更新 | 源码直跑优先国内 npm 镜像；安装版走 CNB Releases / electron-updater（generic feed） |
| 打包 | electron-builder + NSIS；asarUnpack 解包原生依赖，extraResources 携带 OCR 引擎 |
