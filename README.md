# 灵屿岛

一款「灵动岛」风格的桌面文件屏蔽工具：把文件拖到屏幕顶部的胶囊上，自动识别内容并生成屏蔽副本或还原副本；屏蔽值内嵌还原编码，**只要编码未被改动（哪怕从文件里复制出来），随时可一键还原真实内容**。

> 隐私设计原则：**性别、年龄、出生日期等依法用于判断的信息不作为敏感信息，不会屏蔽**；身份证号属于个人身份标识，仍会屏蔽（屏蔽后保留首尾特征，可判断内容类型）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 拖入即处理 | 拖文件/文件夹到屏幕顶部胶囊，**按内容自动判断**：明文 → 生成 `文件名_屏蔽.ext`，含〔编码〕的屏蔽文件 → 生成 `文件名_还原.ext`；**直接读取源文件，只在根目录写出结果，不生成原文件副本**，原位置的文件不会被改动（可在设置中改为处理后移入回收站）；结果文件同名时可选保留两份或覆盖，完成后胶囊与面板都会给出结果提示 |
| 可还原的屏蔽 | 屏蔽形如 `138****5678〔a3f2b1〕`：保留首尾特征可判断内容，`〔〕`内编码是还原钥匙 |
| 随时还原 | 把屏蔽文件重新拖入即可自动生成 `文件名_还原.ext`；粘贴任意含编码的文本可实时还原 |
| 剪贴板恢复 | 复制了含编码的内容时，胶囊提示「识别到含屏蔽信息」，点右侧「还原文本」按钮才还原并写回剪贴板；仅对当前复制的那段文本生效，剪贴板换成别的内容后提示自动失效 |
| 编码防篡改 | 编码被改动时明确提示无法还原，绝不输出错误内容 |
| 快速查找 | 配置根目录后自动建索引、监听变更，秒搜根目录下所有文件；可按「全部/文档/表格/文本/代码/其他」筛选（按钮上的数字为该类别命中数），结果可打开或在文件夹中定位 |
| 全类型支持 | 文本类（txt/md/csv/json/代码等，UTF-8/GBK 自动识别）+ Office（docx/xlsx/pptx） |

## 敏感信息检测范围

- ✅ 手机号（含校验边界）、身份证号（18 位校验码验算）、银行卡号（BIN + Luhn 验算）、电子邮箱
- ✅ 中文姓名（**语境驱动**：角色标签「原告/被告/第三人/代理人/负责人/审判长…」、称呼、`，男｜女` 结构、职业前缀「村医/村委/米婆…」、强敏感信息邻近）
- ✅ 姓名传播：同一文档内首次锚定后，后文只出现名字也会命中；同一批次（如整套卷宗）内跨文件传播
- ✅ 家庭住址（保守组合模式）、护照号、车牌号
- ❌ **不屏蔽**：性别、年龄、出生日期、民族（依法判断需要的数据）
- ❌ **不按姓名屏蔽**：机构名与地名（「广东雷阳律师事务所」「雷州市北和镇…村民委员会」「广东省雷州市」），避免把 `雷州市` 误切成 `雷*市`
- ❌ 误报控制：无语境的姓名（如"今天上午和张伟开会"）不会误屏蔽；姓名后必须是标点/连词/常见谓语，`安排于`、`关于主体`、`文字经` 这类普通词不再被当成名字

## 运行

```bash
npm install
npm start        # 启动灵动岛
npm test         # 核心引擎单元测试（22 项）
```

- **Windows**：双击 [启动灵屿岛.bat](启动灵屿岛.bat)
- **macOS**：首次执行 `chmod +x 启动灵屿岛.command`，之后双击即可（或 `npm start`）

**启动脚本**直接调用 Electron 运行时，不经过 npm。首次使用前需 `npm install`（Electron 下载慢可设镜像：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`）。

## 使用说明

1. **智能处理**：拖入文件 → 自动识别内容；明文生成 `文件名_屏蔽.ext`，含屏蔽编码的文件生成 `文件名_还原.ext`。根目录只留结果文件，不会复制一份原文件进去，胶囊与面板都会提示完成结果
2. **还原文件**：把已屏蔽文件（或任意含〔编码〕的文件）重新拖入即可，无需手动选择操作
3. **还原文本**：从文件里复制了被屏蔽的内容 → 胶囊提示「识别到含屏蔽信息」，点右侧「还原文本」按钮即可（点胶囊其他位置只展开面板）；或在「文本恢复」页粘贴
4. **快速查找**：展开面板「快速查找」→ 输入文件名 → 点类别按钮筛选（按钮数字为该类别命中数，类别栏聚焦后可用 ←→ 切换）→ 回车打开 / Shift+回车 定位
5. **同名文件**：「设置 → 同名文件」选择策略，作用于生成的 `_屏蔽` / `_还原` 结果文件。「保留两份」（默认）在结果同名时自动加序号（如 `_屏蔽_02`），旧结果不动；「覆盖同名」直接更新那份结果（启用时有二次确认）
6. **命名归位**：还原产物（`A_还原.docx`）再次拖入屏蔽时，结果回到原名 `A_屏蔽.docx`（同名按上面的策略处理），不会出现 `A_还原_屏蔽.docx`
7. **设置**：检测项开关、剪贴板识别、自动收起（时长可自定义 5–3600 秒，也可选快捷预设，修改后立即生效；**关闭自动收起后，鼠标点击面板外任意位置即收起面板**）、开机自启、清空记录

## 隐私与安全

- 屏蔽映射库（编码 ↔ 原文）仅存本机 `%AppData%`，经 Windows DPAPI（safeStorage）**加密落盘**
- 工具完全不联网，无任何数据上传
- 清空记录不影响已生成的文件与映射库；映射库在「设置 → 数据」中可见加密状态

## 已知限制

- PDF、图片等二进制格式暂不支持（会明确提示）
- docx/xlsx 中被排版拆分成多个文本片段（run）的敏感值可能漏检（漏检不破坏文档，宁可漏不可错）
- 中文姓名为语境驱动识别：没有任何语境锚点的单次出现（如正文里孤立的「麦穗」）仍可能漏检；反之，紧邻角色标签但其实是普通词的情况已用边界规则过滤
- 姓名识别依赖常见姓氏表（约 130 个单姓 + 30 个复姓），生僻姓氏可能漏检
- 误检可通过「还原」无损找回；漏检建议在屏蔽后人工复核正文中出现的人名
- 屏蔽值还原依赖映射库：请勿删除 `%AppData%` 下的映射库文件

## 项目结构

```
src/
  core/       检测器 / 屏蔽恢复引擎 / 文件管道（纯 JS，可独立测试）
  main/       主进程：双窗口、托盘、IPC、映射库加密存储、索引、剪贴板监听
  renderer/   胶囊 + 主面板 UI（原生 HTML/CSS/JS）
test/         单元测试 + Electron E2E（含截图）
scripts/      图标生成
```
